# Instagram Follower Checker

See who you follow on Instagram that doesn't follow you back.

## How to Use

1. **Download your Instagram data**  
   - Go to [this site.](https://accountscenter.instagram.com/info_and_permissions/dyi)
   - Choose **JSON** format, then wait for Instagram to email you the download link.

2. **Extract the ZIP file you download**  
   Inside, navigate to:
   connections/followers_and_following/
You should find files like:
- `followers_1.json`
- `following.json`

3. **Place the files in the same folder as `main.py`**

4. **Run the script**  
```bash
python3 main.py
